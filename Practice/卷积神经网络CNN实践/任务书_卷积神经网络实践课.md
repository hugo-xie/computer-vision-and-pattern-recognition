# 卷积神经网络实践：运行、训练与测试

使用完整的 PyTorch 代码训练一个小型 CNN，完成 Fashion-MNIST 服饰图像分类。实验包括环境检查、数据读取、模型训练、参数保存和独立测试，所有代码均已提供。

环境安装与故障处理见 [README](README.md)。运行时可选择 [Notebook](卷积神经网络实践课.ipynb)，也可直接执行训练和测试脚本。

## 一、数据与模型

### 数据划分

Fashion-MNIST 每张图像为 `28×28` 的单通道灰度图，共 10 个服饰类别。

| 划分 | 默认数量 | 用途 |
|---|---:|---|
| 训练集 | 10,000 | 更新网络参数 |
| 验证集 | 2,000 | 观察训练效果，选择最佳模型 |
| 测试集 | 10,000 | 加载最终模型后评估分类效果 |

训练集和验证集从官方 60,000 张训练图像中按固定随机种子划分，互不重叠；剩余图像默认不用。测试集使用官方独立测试数据，不参与训练和参数选择。

预处理将像素由 `0–255` 转成 `0–1`，再归一化到 `[-1,1]`。输入 batch 的形状为 `N×1×28×28`，标签为 `0–9` 的整数。

### 网络结构

完整网络定义位于 [cnn_model.py](cnn_model.py)，可以直接运行。

| 层 | 输出形状 |
|---|---|
| 输入 | `N×1×28×28` |
| `Conv2d(1,16,3,padding=1)` + `ReLU` | `N×16×28×28` |
| `MaxPool2d(2)` | `N×16×14×14` |
| `Conv2d(16,32,3,padding=1)` + `ReLU` | `N×32×14×14` |
| `MaxPool2d(2)` | `N×32×7×7` |
| `Flatten` | `N×1568` |
| `Linear(1568,64)` + `ReLU` | `N×64` |
| `Linear(64,10)` | `N×10` |

输出为 10 类的 logits，损失函数为 `CrossEntropyLoss`，优化器为 Adam。训练循环、验证与保存过程已实现，无需补充代码。

## 二、运行环境与准备数据

在项目目录中激活环境并检查设备：

```bash
conda activate cv-cnn
python check_env.py --device cpu
```

出现 `PASS` 表示指定设备已完成一次前向计算、反向传播与参数更新。

下载并检查完整数据：

```bash
python prepare_data.py
```

已有缓存时不会重新下载完整文件。离线使用需要 `data/FashionMNIST/raw/` 中的四个原始文件均已解压，目录结构见 README。

## 三、完成模型训练

### 方式 A：运行 Notebook

打开 `卷积神经网络实践课.ipynb`，选择 `Python (cv-cnn)` 内核，从第一个单元开始顺序运行。模型定义、训练循环、保存和测试代码均可直接执行。

配置单元包含：

```python
DEVICE_CHOICE = "cpu"
TRAIN_SIZE = 10000
VAL_SIZE = 2000
EPOCHS = 3
BATCH_SIZE = 64
LEARNING_RATE = 1e-3
RUN_NAME = "baseline"
```

完成配置后，依次运行环境与数据检查、模型构建、训练和最终测试单元。

### 方式 B：运行脚本

执行训练：

```bash
python train.py --device cpu --epochs 3
```

运行期间查看每轮输出的训练损失、训练准确率、验证损失、验证准确率和耗时。代码会自动保存验证准确率最高轮次的参数。

使用 GPU 时，将设备参数改为 `--device cuda`；兼容 Mac 可使用 `--device mps`。设备必须先通过相应的环境检查。

### 小规模检查与计算量调整

先检查代码流程时，运行：

```bash
python train.py --device cpu --train-size 256 --val-size 128 --epochs 1 --run-name smoke
```

小规模运行仅用于确认流程。正式训练使用默认规模；CPU 计算较慢时可调整为：

```bash
python train.py --device cpu --train-size 5000 --val-size 1000 --epochs 3
```

需要继续观察收敛情况时，可重新运行 5–10 轮训练，例如：

```bash
python train.py --device cpu --epochs 10 --run-name longer
```

每次训练都会重新初始化网络。同名输出会被覆盖，使用不同的 `--run-name` 可保留不同配置的结果。

## 四、加载模型并测试

默认训练结束后执行：

```bash
python test.py --device cpu --checkpoint outputs/baseline_best.pt
```

若使用其他运行名称，需要对应修改参数文件路径。例如：

```bash
python test.py --device cpu --checkpoint outputs/longer_best.pt
```

测试代码会建立相同的网络结构，加载保存的最佳参数，在官方测试集上计算损失和准确率，并保存混淆矩阵与误分类图像。测试过程不更新网络参数。

Notebook 的最终测试单元完成相同操作。调整学习率、轮数或样本规模时，根据验证集表现选择配置；配置确定后再运行最终测试。

## 五、查看并保存结果

以默认 `baseline` 为例：

| 文件 | 内容 |
|---|---|
| `outputs/baseline_best.pt` | 最佳验证轮次的模型参数 |
| `outputs/baseline_history.json` | 各轮训练、验证指标和耗时 |
| `outputs/baseline_config.json` | 本次运行配置 |
| `outputs/baseline_curves.png` | 损失与准确率曲线 |
| `outputs/baseline_test_metrics.json` | 最终测试指标 |
| `outputs/baseline_confusion.png` | 测试集混淆矩阵 |
| `outputs/baseline_mistakes.png` | 测试集误分类图像 |

记录本次实际结果：

| 项目 | 运行结果 |
|---|---|
| 操作系统、Python / torch / torchvision 版本 | |
| 实际训练设备 | |
| 训练 / 验证 / 测试样本数 | |
| 训练轮数、batch size、学习率 | |
| 最佳验证准确率及对应轮次 | |
| 最终测试准确率 | |
| 最佳模型文件路径 | |

检查训练曲线：训练损失是否总体下降，验证准确率是否随训练提高；若训练准确率持续提高而验证表现下降，可能出现过拟合。不同设备、版本、数据规模和随机性会影响结果，不以固定准确率作为唯一完成条件。
